# Security policy

**English** · [Magyar](#biztonsági-szabályzat)

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately through
[GitHub Security Advisories](https://github.com/GeRiY/callgraph/security/advisories/new).
Include the version (`callgraph --version`), your OS, and steps to reproduce. You will get an answer within a few days.

## Supported versions

Only the [latest release](https://github.com/GeRiY/callgraph/releases/latest) receives fixes.
Update with `bash ~/.claude/skills/callgraph/callgraph.sh update`.

# Biztonsági szabályzat

## Sérülékenység bejelentése

Biztonsági hibát **ne** nyilvános issue-ban jelezz, hanem privátban, a
[GitHub Security Advisories](https://github.com/GeRiY/callgraph/security/advisories/new) oldalon.
Add meg a verziót (`callgraph --version`), az operációs rendszert és a reprodukálás lépéseit. Néhány napon belül válaszolunk.

## Támogatott verziók

Javítást csak a [legfrissebb kiadás](https://github.com/GeRiY/callgraph/releases/latest) kap.
Frissítés: `bash ~/.claude/skills/callgraph/callgraph.sh update`.
