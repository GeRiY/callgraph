callgraph.sh — vékony burok az callgraph (Rust) fölött; tömör, token-hatékony PHP / JS / TS / Vue fájl-kontextus agentek számára,
(a PHP-t, a .vue/.js/.ts fájlokat és a CSS/SCSS/JSON/MD-t az callgraph elemzi, egy sémában;
 Vue-n: props, emits (emit:<név>), template (komponensek, eseménykezelők), setup, hookok;
 kereshető kulcsok: route::<név>, i18n::<kulcs>, vue::emit:<név>, <fájl>::<export>)
a fájl beolvasása NÉLKÜL (metódusok + hívás-gráf, kategorizálva).

Használat:
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl>                    outline (alapértelmezett) — lásd lent
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl> --format outline    ua., explicit
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl> --format api        publikus szerződés + docblock, hívás-gráf NÉLKÜL
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl> --format stats      kategória-statisztika
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl> --format mermaid    Mermaid flowchart (vizualizációhoz)
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl> --format dot        Graphviz DOT (vizualizációhoz)
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl> --format json       nyers kategorizált JSON (a callgraph elemző kimenete)
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl>[::metódus] --format flow  if/match/switch ágak sortartománnyal (feltétel → mit hív)
  bash ~/.claude/skills/callgraph/callgraph.sh <mappa> --format summary   fájlonként 1 sor (osztály, metódusszám, docblock)
  bash ~/.claude/skills/callgraph/callgraph.sh <mappa> --format coverage  dokumentálatlan publikus metódusok
  bash ~/.claude/skills/callgraph/callgraph.sh <mappa> --format hotspots  Top 20 metódus fokszám szerint (in/out) — hol nézz körül elsőként
  bash ~/.claude/skills/callgraph/callgraph.sh <mappa|fájl1 fájl2 ...> --format outline
                                                több fájl/mappa — outline-ok egymás után
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl>::<metódusnév>       CSAK egy metódus — a legtömörebb forma
                                                nagy fájloknál, ha egy konkrét metódus érdekel
                                                (bármelyik --format-tal kombinálható)
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl|mappa> --grep <minta>       csak a mintára illeszkedő célú hívások
                                                (csak az illeszkedő hívást tartalmazó metódusok/fájlok — "hol hívják");
                                                minden hívás a forrássorával: "L25 │ $this->repo->find($id)";
                                                egy hívón belül az azonos sorok összevonva ("L12, L40 │ …"), hívónként
                                                legfeljebb 3 sor, utána "… +N további: L55, L61";
                                                "via Resolver" = interfészen / trait-en / szülő-típuson át hívva
                                                (a Típus::metódus minta ezeket a hívásokat is megtalálja)
                                                Rust: "?::m" = ismeretlen fogadó-típus; a Típus::m minta név szerint is megtalálja
                                                TS: a típusos fogadó (this.repo.find(), ha "repo: Repo") a Típus::m mintára illik;
                                                típus nélküli / any / unió fogadó feloldatlan (a metódusnévvel keresd)
  bash ~/.claude/skills/callgraph/callgraph.sh <mappa> --grep <minta> --depth N [--guess]
                                                hívók hívói N szintig (hatáselemzés); --guess: a feloldatlan,
                                                csak név szerinti egyezéseket is ("?")
  Utak: ha a projekt-gyökér többször ismétlődne, az első sor "gyökér: /abs/projekt", utána minden út ehhez relatív
  (a következő hívásban ugyanazzal a --project-tel változatlanul használható).
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl>::<metódus> [...] --body   a metódus(ok) forrása sorszámozva, tömören: docblock
                                                és üres sorok nélkül, a törzsön belüli megjegyzések maradnak (a sorszámok
                                                pontosak; az "==" fejléc jelzi: "docblock L…-… kihagyva")
                                                --doc: docblockkal; --raw: a pontos, szűretlen forrás
  bash ~/.claude/skills/callgraph/callgraph.sh <mappa> --grep <minta> --body    a talált hívó metódusok forrása
  bash ~/.claude/skills/callgraph/callgraph.sh <fájl> --lines <n>-<m>           tetszőleges sáv sorszámozva (pl. view-fájl)
  bash ~/.claude/skills/callgraph/callgraph.sh <mappa|fájl> --strings <minta>   string-literálok (hibaüzenet, kulcs) helye
  bash ~/.claude/skills/callgraph/callgraph.sh <mappa|fájl> --const <minta>     konstans-hivatkozások, -definíciók és továbbexportálások
                                                (PHP osztálykonstans / use const, Rust const/static / pub use, JS/TS export { })

Jegyzetek (pilot — rövid jegyzet egy fájlhoz vagy metódushoz, a forráson kívül: <projekt>/.callgraph/notes.jsonl):
  bash ~/.claude/skills/callgraph/callgraph.sh note add <fájl>[::<metódus>] "<szöveg>" [--project alias]
                                                kiírja az új jegyzet azonosítóját; a horgony a metódus NEVE (Osztály::metódus is jó)
  bash ~/.claude/skills/callgraph/callgraph.sh note list [<fájl|mappa>] [--project alias]
                                                "<id>  <fájl>::<Osztály>::<metódus>  2026-11-05 20:27  📝 <szöveg>";
                                                [árva] = a metódus már nincs a fájlban
  bash ~/.claude/skills/callgraph/callgraph.sh note rm <id> [--project alias]
  bash ~/.claude/skills/callgraph/callgraph.sh <mappa|fájl> --notes <minta>    jegyzetek keresése (regex a szövegre vagy a horgonyra, kis/nagybetű mindegy)
  Az outline a fájl-fejléc / a metódus alatt mutatja: "📝 2026-11-05 20:27 · <szöveg>" (legújabb elöl, legfeljebb 3),
  a --body a metódus forrása fölött. Az idő UTC.

Honnan induljak a feladattal (egy hívás a feladat neveivel és fogalmaival):
  bash ~/.claude/skills/callgraph/callgraph.sh locate <kifejezés>... [--all] [--project alias]
                                                rangsorolt fájlok a projekt-térképből (forrás olvasása nélkül), fájlonként
                                                legfeljebb 3 indoklással: pontos definíció, fájlnév, név-részlet (camelCase /
                                                snake_case / kebab-case, egyes / többes szám), string-literál, hívás; "hívók: N";
                                                az első 5 fájl, --all: minden egyező fájl; a "nincs találat: …" a meg nem
                                                talált, a "túl általános" a 30-nál több fájlban egyező kifejezéseket sorolja

Előre-frissítés (git pull vagy sok szerkesztés után, hogy a következő lekérdezésnek ne kelljen újraelemeznie):

  bash ~/.claude/skills/callgraph/callgraph.sh refresh <fájl|mappa> ... [--project alias]   csak ezek (a gyökérhez képest)
                                                kiírja: "frissítés: N frissítve, N eltávolítva, N változatlan"; --background:
                                                azonnal visszatér, a frissítés leválasztott folyamatban fut; ha egy másik
                                                frissítés fut, kihagyja ("frissítés: kihagyva")
  bash ~/.claude/skills/callgraph/callgraph.sh hook install|uninstall|status   Claude Code-hook (~/.claude/settings.json):
                                                Edit / Write / MultiEdit után a szerkesztett fájl a háttérben frissül
                                                (csak regisztrált, vagy már .callgraph/ mappával rendelkező projektben);
                                                a többi beállítás marad, előtte settings.json.bak mentés készül
  Az MCP-szerver (callgraph mcp) a betöltött projekteket figyeli, és a változott fájlokat magától frissíti
  (kikapcsolás: CALLGRAPH_WATCH=0).

  futásnál rákérdez; eltávolítás: claude mcp remove -s user callgraph). A szerver rövid használati útmutatót küld a
  kliensnek (melyik eszköz mire, hogyan olvasd a kimenetet); a guide eszköze a teljes SKILL.md-t adja.

Frissítés (a GitHub Releases-ből; a projects.json, a lang, az errors.jsonl, a feedback.jsonl és az update-check.json megmarad):
  bash ~/.claude/skills/callgraph/callgraph.sh update --check         van-e újabb kiadás? (nem változtat semmit)
  bash ~/.claude/skills/callgraph/callgraph.sh update                 az újabb kiadás letöltése és telepítése
  bash ~/.claude/skills/callgraph/callgraph.sh update --force         újratelepítés akkor is, ha naprakész
  bash ~/.claude/skills/callgraph/callgraph.sh update --from <zip>    telepítés helyi zipből / címről (callgraph-<os>-<arch>.zip)
  A letöltést a kiadás SHA256SUMS fájlja szerint ellenőrzi (eltérésnél vagy ha hiányzik, semmit nem telepít);
  --insecure-skip-checksum kihagyja. --from: a --sha256 <hex> vagy a zip melletti SHA256SUMS szerint, különben figyelmeztet.
  Automatikus ellenőrzés: naponta legfeljebb egyszer, a háttérben; újabb kiadásnál egy „ℹ callgraph X elérhető” sor
  kerül a kimenet végére. Kikapcsolás: CALLGRAPH_UPDATE_CHECK=0 (CI mellett és skill-telepítésen kívül magától ki van kapcsolva).
  MCP-szerver: a "args": ["mcp", "--auto-update"] (ajánlott) a szerver indításakor telepíti az újabb kiadást (naponta
  legfeljebb egyszer, kötelező SHA256SUMS-szal, ugyanazokat a fájlokat, mint az update), és újraindul; bármilyen hibánál
  a jelenlegi verzió fut, és egy sor megy a stderr-re. Kapcsoló nélkül a munkamenet első eszköz-eredménye kapja meg a
  „ℹ callgraph X elérhető” sort. Mindkettő csak a skill-mappába ír; CALLGRAPH_UPDATE_CHECK=0: semmi hálózat.
