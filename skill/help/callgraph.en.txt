callgraph.sh — thin wrapper over callgraph (Rust); compact, token-efficient PHP / JS / TS / Vue file context for agents,
(callgraph parses PHP, .vue/.js/.ts files and CSS/SCSS/JSON/MD into one schema;
 on Vue: props, emits (emit:<name>), template (components, event handlers), setup, hooks;
 searchable keys: route::<name>, i18n::<key>, vue::emit:<name>, <file>::<export>)
WITHOUT reading the file (methods + call graph, categorized).

Usage:
  bash ~/.claude/skills/callgraph/callgraph.sh <file>                    outline (default) — see below
  bash ~/.claude/skills/callgraph/callgraph.sh <file> --format outline    same, explicit
  bash ~/.claude/skills/callgraph/callgraph.sh <file> --format api        public contract + docblock, WITHOUT the call graph
  bash ~/.claude/skills/callgraph/callgraph.sh <file> --format stats      category statistics
  bash ~/.claude/skills/callgraph/callgraph.sh <file> --format mermaid    Mermaid flowchart (for visualization)
  bash ~/.claude/skills/callgraph/callgraph.sh <file> --format dot        Graphviz DOT (for visualization)
  bash ~/.claude/skills/callgraph/callgraph.sh <file> --format json       raw categorized JSON (the callgraph parser's output)
  bash ~/.claude/skills/callgraph/callgraph.sh <file>[::method] --format flow  if/match/switch branches with line ranges (condition → what it calls)
  bash ~/.claude/skills/callgraph/callgraph.sh <dir> --format summary   one line per file (class, method count, docblock)
  bash ~/.claude/skills/callgraph/callgraph.sh <dir> --format coverage  undocumented public methods
  bash ~/.claude/skills/callgraph/callgraph.sh <dir> --format hotspots  top 20 methods by degree (in/out) — where to look first
  bash ~/.claude/skills/callgraph/callgraph.sh <dir|file1 file2 ...> --format outline
                                                several files/dirs — outlines one after another
  bash ~/.claude/skills/callgraph/callgraph.sh <file>::<methodname>       ONLY one method — the most compact form
                                                for large files, when you care about one specific method
                                                (combinable with any --format)
  bash ~/.claude/skills/callgraph/callgraph.sh <file|dir> --grep <pattern>       only calls whose target matches the pattern
                                                (only the methods/files containing a matching call — "where is it called");
                                                each call with its source line: "L25 │ $this->repo->find($id)";
                                                "via Resolver" = called through an interface / trait / parent type
                                                (a Type::method pattern also finds those calls)
                                                Rust: "?::m" = receiver type unknown; a Type::m pattern still finds it (by name)
                                                TS: typed receivers (this.repo.find() with "repo: Repo") match Type::m;
                                                untyped / any / union receivers stay unresolved (search by method name)
  bash ~/.claude/skills/callgraph/callgraph.sh <dir> --grep <pattern> --depth N [--guess]
                                                callers of callers up to N levels (impact analysis); --guess: also the
                                                unresolved, name-only matches ("?")
  Paths: when several would repeat the project root, the first line is "root: /abs/project" and every path after it is
  relative to that root (usable as-is in the next call with the same --project).
  bash ~/.claude/skills/callgraph/callgraph.sh <file>::<method> [...] --body   source of the method(s), line-numbered, compact: no
                                                docblock, blank or comment-only lines (the line numbers stay exact)
                                                --doc: with the docblock; --raw: the exact, unfiltered source
  bash ~/.claude/skills/callgraph/callgraph.sh <dir> --grep <pattern> --body    source of the caller methods found
  bash ~/.claude/skills/callgraph/callgraph.sh <file> --lines <n>-<m>           any line range, line-numbered (e.g. a view file)
  bash ~/.claude/skills/callgraph/callgraph.sh <dir|file> --strings <pattern>   where string literals (error message, key) occur
  bash ~/.claude/skills/callgraph/callgraph.sh <dir|file> --const <pattern>     constant references, definitions and re-exports
                                                (PHP class constants / use const, Rust const/static / pub use, JS/TS export { })

Language (of the terminal output and the help: en = English, default; hu = Hungarian):
  bash ~/.claude/skills/callgraph/callgraph.sh set-lang                 the current language and where it comes from
  bash ~/.claude/skills/callgraph/callgraph.sh set-lang <en|hu>         save the language (to the skill dir's lang file)
                                                also switches the skill instructions (SKILL.md) to that language;
                                                restart Claude Code to reload the skill
  CALLGRAPH_LANG=<en|hu> bash ~/.claude/skills/callgraph/callgraph.sh …   for one run (overrides the saved one)

Update (from GitHub Releases; projects.json, lang, errors.jsonl, feedback.jsonl, update-check.json are kept):
  bash ~/.claude/skills/callgraph/callgraph.sh update --check         is there a newer release? (changes nothing)
  bash ~/.claude/skills/callgraph/callgraph.sh update                 download and install the newer release
  bash ~/.claude/skills/callgraph/callgraph.sh update --force         reinstall even if up to date
  bash ~/.claude/skills/callgraph/callgraph.sh update --from <zip>    install from a local zip / URL (callgraph-<os>-<arch>.zip)
  The download is verified against the release's SHA256SUMS (nothing is installed on a mismatch or if it is missing);
  --insecure-skip-checksum skips this. --from: verified by --sha256 <hex> or a SHA256SUMS next to the zip, else a warning.
  Automatic check: at most once a day, in the background; a newer release adds one "ℹ callgraph X is available" line
  to the end of the output. Off: CALLGRAPH_UPDATE_CHECK=0 (also off when CI is set or outside a skill installation).

Output limit: above 400 lines the directory outline switches to summary, the single-file one to a method index;

Engine: the logic (project alias resolution, `show`, error ids) lives in the `callgraph wrap` subcommand;
this wrapper only prints the help and forwards.
